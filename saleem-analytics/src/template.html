Month by month

MoM and YoY use orders per day, so months of different length and the current partial month compare fairly. The orange tag shows how many Ramadan days fell in that month, since Ramadan moves about 11 days earlier each year and distorts YoY.

Service breakdown

Previous period = the same number of days immediately before. Last year = the same dates shifted back 364 days, so weekdays line up. Ad spend here is spend on campaigns for that service only; general, brand and app campaigns are shown in the ads section.

Unique patients

Each patient counted once per month. New = the month of their first-ever service with Saleem; returning = everyone else served that month. The service chips above don't apply here; pick a category on the right.

This section needs one extra Metabase export. The main export counts patients per day, so unique patients can't be worked out from it.

  1. In Metabase, create a new SQL question and paste the query (Copy SQL below).
  2. Run it with no date filter, then download the results as CSV.
  3. Click Load CSV at the top of this page and pick that file.

Unique patients can't be added across months or categories: someone treated in both March and April counts once in each month. For a longer period, compare month by month.

Meta ads

Campaigns are matched to services by name. Results are counted the way each campaign's objective defines them: WhatsApp conversations for message campaigns, purchases, installs or leads for the others. Cost per order divides spend by orders for the matching services in the same dates, so it is a rough efficiency signal, not attribution.

Holiday effects

Orders per day during each holiday compared with the same weekdays in the four weeks before and after. Uses the services and statuses selected above and all available history. Grey years had too little volume to count toward the average.

Events log

Political, economic and marketing events shown on the trend chart. Add Saleem's own events such as price changes, launches, contracts or outages.

Events you add are saved in this browser only. Use "Copy as CSV" and send them to Claude to make them permanent.
